# แผนงานพัฒนาระบบตรวจสอบความเชื่อมโยงบทเรียน AI (Cross-Topic Knowledge Synergy)

ระบบจะทำการวิเคราะห์เนื้อหาบทเรียนใหม่ที่ผู้ใช้อัปโหลด เปรียบเทียบกับทั้ง **วิชาในแผนการเรียน (Study Plans)** และ **บทเรียนที่เคยบันทึกไว้ในระบบ (Saved Lesson Summaries)** โดย AI จะระบุความสัมพันธ์และอธิบายว่าแต่ละหัวข้อสนับสนุน เกื้อหนุน หรือต่อยอดความรู้กันอย่างไร

---

## 1. การเปลี่ยนแปลงในส่วนหลังบ้าน (Backend: `server.ts`)

- **ปรับปรุง API `/api/ai/summarize-lesson`**:
  - รองรับพารามิเตอร์ `existingContext` ซึ่งส่งรายชื่อวิชาในแผนการเรียน (ชื่อวิชา, ประเภทการสอบ/การบ้าน, สรุปขอบเขต, หัวข้อย่อย) และประวัติบทเรียนที่เคยสรุปไว้
  - ปรับ Prompt ของ Gemini 3.8 Flash ให้ทำการ Cross-Check ความสัมพันธ์ขององค์ความรู้ (Knowledge Interconnection Analysis):
    - ค้นหาจุดที่ทฤษฎี คอนเซปต์ หรือคำศัพท์มีความเกี่ยวข้อง ต่อเนื่อง หรือสนับสนุนกัน
    - ระบุประเภทความสัมพันธ์ (`relationshipType`):
      - `prerequisite` (ความรู้พื้นฐานที่ต้องใช้ต่อยอด)
      - `complementary` (เสริมความเข้าใจเนื้อหาซึ่งกันและกัน)
      - `cross_domain` (การประยุกต์ใช้ข้ามศาสตร์/บูรณาการข้อสอบ)
      - `supporting_evidence` (ทฤษฎีหรือหลักการที่ใช้อ้างอิงสนับสนุน)
    - ระบุคำอธิบายว่าเชื่อมโยงกันอย่างไร (`connectionSummary`)
    - ระบุวิธีที่เนื้อหานี้สนับสนุนความเข้าใจวิชาเดิม (`howItSupports`)
    - คำแนะนำเพื่อเตรียมสอบหรือทบทวนร่วมกัน (`studySynergyTip`)
  - มีระบบ Fallback เชิงอนุมานความเชื่อมโยงที่ฉลาดแม่นยำแม้ขณะออฟไลน์หรือไม่มี API Key

## 2. การเปลี่ยนแปลงในส่วนหน้าบ้าน (Frontend)

### `src/components/LessonSummarizerView.tsx`
- **รับ Prop `plans: PlanItem[]`** จาก `App.tsx`
- อัปเดต TypeScript Interface: `KnowledgeLinkItem` และขยาย `LessonSummaryData` ให้มีฟิลด์ `relatedLinks?: KnowledgeLinkItem[]`
- เมื่อกดปุ่ม "ให้ AI สรุปเนื้อหาบทเรียน":
  - รวบรวมบริบทของวิชาในแผนการเรียนปัจจุบัน (`plans`) และบทเรียนที่เคยบันทึกไว้ (`savedList`) ส่งไปพร้อมกับคำขอสรุป
- **ออกแบบและเพิ่มส่วนแสดงผล "การ์ดเชื่อมโยงความรู้ & บูรณาการข้ามวิชา" (Knowledge Synergy Network)** ด้านล่างผลสรุป:
  - Header ป้ายสัญลักษณ์โครงข่ายความรู้ (`hub`, `share_location`)
  - ป้ายแสดงจำนวนความเชื่อมโยงที่ตรวจพบ (เช่น *"พบ 2 จุดเชื่อมโยงกับวิชาในระบบของคุณ"*)
  - การ์ดความสัมพันธ์แต่ละรายการประกอบด้วย:
    - ป้ายประเภทความสัมพันธ์พร้อมสีสื่อความหมายชัดเจน (พื้นฐานต่อยอด / เสริมความเข้าใจ / บูรณาการข้ามวิชา)
    - ชื่อวิชา/บทเรียนเป้าหมายที่เชื่อมโยงถึง พร้อม Badge ระบุประเภท (`แผนการเรียน` หรือ `บทเรียนที่เคยสรุป`)
    - **หัวข้อที่เชื่อมโยงกันอย่างไร (Connection Analysis)**: อธิบายจุดตัดของแนวคิด
    - **สนับสนุนกันอย่างไร (Synergy & Support)**: ประโยชน์ในการทำความเข้าใจ
    - **เคล็ดลับการอ่านควบคู่ (Synergy Study Tip)**: วิธีทบทวนทั้งสองเรื่องร่วมกันเพื่อจำได้แม่นยำขึ้น
    - ปุ่มคลิกลิงก์เพื่อสลับไปยังหน้าสรุปวิชานั้นๆ ได้ทันที

## 3. แผนการทดสอบและตรวจสอบ (Verification Plan)

1. **Static Analysis & Types**:
   - รัน `lint_applet` (`tsc --noEmit`) เพื่อตรวจเช็คความถูกต้องของ TypeScript Types ทั้งหมด
2. **Compilation**:
   - รัน `compile_applet` เพื่อยืนยันว่าการ Build ผ่าน 100% ไม่มีข้อผิดพลาด
3. **ฟังก์ชันการทำงาน**:
   - ทดสอบสรุปบทเรียนและตรวจสอบว่าแสดงการ์ดเชื่อมโยงความรู้กับวิชาที่มีในระบบอย่างสมบูรณ์
   - ตรวจสอบทั้งกรณีที่ตรวจพบความเชื่อมโยง และกรณีที่เป็นเนื้อหาใหม่ที่ยังไม่มีจุดเชื่อมโยง
